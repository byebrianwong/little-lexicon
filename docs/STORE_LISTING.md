## Full description

Little Lexicon helps native English speakers master erudite, GRE-and-beyond
vocabulary and actually retain it. It combines a modern spaced-repetition engine (FSRS)
with retrieval-based game modes, example sentences at every encounter, and
audio, so each word gets the varied, spaced practice that memory research says
it needs.

What you get:

- A daily session that mixes new words with the reviews that are due, sized to a
  goal you set.
- Game modes that escalate as a word matures: recognition, fill-the-blank,
  type-the-word, synonym and antonym matching, listening, and writing your own
  sentence.
- Progress you can see: words known and learning, retention percentage, a streak
  with a limited freeze, XP and levels, an activity heatmap, and a forecast of
  upcoming reviews.
- Audio on every word and sentence.

Free includes the core game modes and a set number of new words per day. Pro
unlocks unlimited new words, every game mode, write-your-own-sentence feedback,
personalized examples, advanced stats, and offline audio.
